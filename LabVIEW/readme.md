# LabVIEW Stalin Sort Readme

This folder contains the LabVIEW implementation of Stalin Sort.

Files in this folder:
* stalin-sort.vim: Stalin Sort implementation as malleable VI
* stalin-sort-use.vi: Example how to use the stalin-sort.vim with different data types
* PNG files showing the Block Diagrams and Front Panels of the VIs

Code is created with LabVIEW 2025 Q1.
